# Nox Android Updater

System aktualizacji aplikacji Nox Android.

## Manifest

Plik `update.json` zawiera:
- aktualną wersję aplikacji,
- numer wersji,
- adres pobrania APK,
- informacje o zmianach,
- informację, czy aktualizacja jest obowiązkowa.

## Status

Updater przygotowany pod automatyczne aktualizacje Nox.
